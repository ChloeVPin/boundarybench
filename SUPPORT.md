# Support

BoundaryBench support is organized by the type of question.

Use [GitHub Discussions](https://github.com/ChloeVPin/boundarybench/discussions) for installation help, research design questions, adapter ideas, and general usage. Use the issue forms for reproducible implementation defects and scenario proposals.

Report unsafe execution behavior, exposed data, or credential material privately through the repository Security tab. Do not place sensitive details in a public issue.

When asking for help, include your Python version, operating system, BoundaryBench version or commit, the command you ran, and the complete local error message. Remove any private path, token, or account data before posting.
