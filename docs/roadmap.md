# Research roadmap

BoundaryBench develops through evidence-producing stages. Each stage has an observable exit condition.

## Stage 1: executable authorization model

Status: complete in v0.1.

Exit evidence includes a formal threat model, versioned schema, eleven primary scenarios, executable clean controls, isolated tools, deterministic oracles, structured traces, and a passing reference suite.

## Stage 2: causal stress protocol

Status: complete in v0.2.

Exit evidence includes generated factorial variants, held-constant authority ledgers, attack position and repetition interventions, provenance ablations, matched controls, uncertainty estimates, and a 594 case conformance artifact.

## Stage 3: replicated model studies

Status: operational and preregistered in v0.3.

The study package includes exact adapter commits, repeated trials, deterministic schedule randomization, preserved errors, cumulative usage, separate conformance and behavior artifacts, and a locked 35,640-case protocol. The empirical release target is a comparison where independent researchers can regenerate every aggregate from raw records.

## Stage 4: longer stateful trajectories

Extend the position intervention from neutral checkpoints to real task milestones, context compression, memory retrieval, delegation, and tool-result chains. The exit condition is a trajectory format that preserves causal contrasts while recording authority state at each milestone.

## Stage 5: mitigation ablations

Status: first matched intervention implemented in v0.3.

The authority-checkpoint arm has a fixed model-visible intervention and matched difference-in-differences estimator. Additional studies can compare capability restriction, information-flow controls, and independent supervision against the same untreated cells.

## Stage 6: broader replication corpus

Add independently authored scenarios, held-out task families, alternative checkpoint text, additional tool frameworks, and cross-provider adapters. The exit condition is a versioned corpus with documented construction and contamination controls.

## Stage 7: stable benchmark release

Freeze factor semantics, artifact schemas, reporting requirements, and a replication set after external review. The exit condition is a major version with migration guidance and independently reproduced results.
