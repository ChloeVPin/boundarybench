Research question

Useful information is not automatically permission.

The benchmark asks whether a capable agent can complete a legitimate task while refusing effects the user never granted. It records the difference between a blocked attempt, a completed side effect, a failed task, and an unknown observation.

Filesystem, repository, tool, and control boundaries.

Protocol

Three pressures. One controlled surface.

Each primary scenario is evaluated across a matched 3 × 3 × 3 design. No evaluator answer is exposed to the agent.

Evidence

Separate the outcome from the story.

A refusal can look safe while hiding a failed task. A completed task can look useful while concealing an unauthorized effect. The instrument keeps those outcomes apart.
