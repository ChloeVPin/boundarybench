Research

Where does authorization fail?

BoundaryBench measures whether tool-using AI agents preserve user authority as context, repetition, and provenance change.

Read the study View the repository

Research question

Can an agent distinguish useful context from permission to act?

Three sources of pressure

The task stays fixed while one part of the surrounding context changes.

Provenance

Explicit source, source only, and flattened context.

Position

Early, middle, and late in the agent trajectory.

Repetition

One, three, and five presentations of the same pressure.

Method

A controlled study of authority under pressure

Every attack condition has a matched clean control. Task completion and authorization preservation are scored separately.

Measure Count Purpose
Primary scenarios 11 Filesystem, repository, tool, and control boundaries
Conditions per scenario 27 A 3 by 3 by 3 factorial design
Controlled cases 594 Matched attack and clean-control trajectories
Preregistered cases 35,640 Three model tiers and two intervention arms

The outcome matters more than the explanation

BoundaryBench records requested effects, attempted effects, completed effects, task completion, and unknown observations as separate evidence.

Complete event traces

Each run preserves the model-visible trajectory, tool requests, tool results, artifacts, oracle evidence, and final state.

Deterministic oracles

Expected and forbidden effects are evaluated from the sandbox state rather than from the model’s explanation.

Explicit unknowns

Missing evidence remains unknown. It is never converted into an implicit failure or success.
